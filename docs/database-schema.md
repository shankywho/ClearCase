# ClearCase: DynamoDB Single-Table Design & Data Access Architecture

This document specifies the DynamoDB Single-Table schema, Global Secondary Indexes (GSIs), TTL configurations, and access patterns designed for **Project ClearCase** (Offline-First, Voice-Native AI Dispute Resolution Mesh for Bharat).

---

## 1. Table Overview

* **Table Name**: `ClearCaseTable` (or `ClearCaseTable-local` in local development)
* **Partition Key (PK)**: `String`
* **Sort Key (SK)**: `String`
* **Billing Mode**: `PAY_PER_REQUEST` (On-Demand Capacity)
* **Time-to-Live (TTL)**: Attribute `otpExpiry` (Epoch timestamp in seconds)

---

## 2. Global Secondary Index (GSI): `MediatorQueueIndex`

To support Panchayat and Lok Adalat mediators without expensive table scans, a dedicated GSI is defined for local jurisdiction and status filtering.

* **Index Name**: `MediatorQueueIndex`
* **GSI Partition Key (`GSI1PK`)**: `String` formatted as `JURISDICTION#<district>`
* **GSI Sort Key (`GSI1SK`)**: `String` formatted as `STATUS#<status>`
* **Projection**: `ALL`

### Why This Design?
In rural India, dispute mediation occurs at the administrative district/block/panchayat level. When a Panchayat mediator opens the dashboard, they need an immediate query of disputes in their district flagged as `MEDIATOR_REVIEW_REQUIRED` or `CONSENT_PENDING`. This index provides an $O(1)$ query with zero table scans.

## 3. Entity Definitions & Key Patterns

### 3.1. Case Metadata Entity

Represents the core dispute intake, voice transcription, statutory RAG matching result, neutral settlement draft, and escalation state.

* **PK**: `CASE#<caseId>` (e.g., `CASE#7a8e2b9c-1234-5678-9abc-def012345678`)
* **SK**: `METADATA`
* **GSI1PK**: `JURISDICTION#<district>` (e.g., `JURISDICTION#Varanasi`)
* **GSI1SK**: `STATUS#<status>` (e.g., `STATUS#MEDIATOR_REVIEW_REQUIRED`)

#### Attributes:
| Attribute | Type | Description |
| :--- | :--- | :--- |
| `id` | String | Unique Case UUID |
| `title` | String | Plain-language dispute headline |
| `description` | String | Full summary of dispute |
| `originalAudioUrl` | String | S3 audio URI of recorded voice grievance |
| `transcribedText` | String | Voice transcription in regional dialect |
| `englishTranslation` | String | Normalized semantic translation for RAG |
| `dialect` | String | Regional dialect (e.g., `bhojpuri`, `haryanvi`, `awadhi`, `hindi`) |
| `state` | String | State jurisdiction (e.g., `Uttar Pradesh`, `Haryana`) |
| `district` | String | Administrative district (e.g., `Varanasi`, `Sonipat`) |
| `village` | String | Optional village/mauza name |
| `status` | String | `INTAKE_PENDING` \| `EVALUATION_IN_PROGRESS` \| `SETTLEMENT_PROPOSED` \| `MEDIATOR_REVIEW_REQUIRED` \| `CONSENT_PENDING` \| `RESOLVED` \| `REJECTED` |
| `confidenceScore` | Number | AI confidence score ($0.0 - 1.0$) from statutory matching |
| `escalationReason` | String | Justification if routed to human mediator |
| `statutoryReferences` | List[Map] | List of matched statutory sections `[{ act, section, clauseTitle, relevanceSummary }]` |
| `settlementDraft` | String | Neutral, plain-language settlement proposal generated by Bedrock |
| `settlementAudioUrl` | String | Regional TTS audio URL for illiterate citizen playback |
| `onChainTxHash` | String | Polygon Amoy settlement registry transaction hash |
| `createdAt` | String | ISO 8601 creation timestamp |
| `updatedAt` | String | ISO 8601 update timestamp |

---

### 3.2. Party Entity (Petitioner / Respondent / Mediator)

Represents each disputant or mediator assigned to a case, holding contact information, dual-party OTP credentials, and digital consent status.

* **PK**: `CASE#<caseId>`
* **SK**: `PARTY#<phone>` (e.g., `PARTY#+919876543210`)
* **GSI1PK**: *None*
* **GSI1SK**: *None*

#### Attributes:
| Attribute | Type | Description |
| :--- | :--- | :--- |
| `caseId` | String | Foreign key reference to Case UUID |
| `phone` | String | Normalized E.164 phone number |
| `name` | String | Disputant legal/informal name |
| `role` | String | `PETITIONER` \| `RESPONDENT` \| `MEDIATOR` |
| `otp` | String | 6-digit one-time password for e-consent |
| `otpExpiry` | Number (TTL) | **Epoch timestamp in seconds**. Automatically pruned by DynamoDB after expiry |
| `consentStatus` | String | `PENDING` \| `ACCEPTED` \| `REJECTED` |
| `consentTimestamp` | String | ISO 8601 timestamp when consent was granted |
| `createdAt` | String | ISO 8601 creation timestamp |
| `updatedAt` | String | ISO 8601 update timestamp |

---

### 3.3. Audit Log Entity

Maintains a tamper-evident, append-only chronological trail of every event in the dispute lifecycle before on-chain anchoring.

* **PK**: `CASE#<caseId>`
* **SK**: `AUDIT#<isoTimestamp>#<action>` (e.g., `AUDIT#2026-09-18T09:30:00.000Z#INTAKE_RECORDED`)

#### Attributes:
| Attribute | Type | Description |
| :--- | :--- | :--- |
| `caseId` | String | Case UUID |
| `action` | String | Event name (`INTAKE_RECORDED`, `RAG_MATCHED`, `DRAFT_GENERATED`, `OTP_VERIFIED`, `ONCHAIN_ANCHORED`) |
| `actor` | String | Originating actor (`CITIZEN`, `BEDROCK_AGENT`, `MEDIATOR`, `SYSTEM`) |
| `details` | Map | Event payload / metadata |
| `timestamp` | String | ISO 8601 timestamp |

## 4. Access Patterns Matrix

| # | Access Pattern | Target | Key Condition Expression / Query | Method |
| :--- | :--- | :--- | :--- | :--- |
| **AP-01** | Create new grievance case | Base Table | `PK = CASE#<id>`, `SK = METADATA` | `PutCommand` |
| **AP-02** | Get case metadata | Base Table | `PK = CASE#<id>`, `SK = METADATA` | `GetCommand` |
| **AP-03** | Get case with all parties (Single Query Join) | Base Table | `PK = CASE#<id>` | `QueryCommand` |
| **AP-04** | Add party to case with OTP TTL | Base Table | `PK = CASE#<id>`, `SK = PARTY#<phone>` | `PutCommand` |
| **AP-05** | Get specific party in a case | Base Table | `PK = CASE#<id>`, `SK = PARTY#<phone>` | `GetCommand` |
| **AP-06** | Get all parties for a case | Base Table | `PK = CASE#<id> AND begins_with(SK, 'PARTY#')` | `QueryCommand` |
| **AP-07** | Atomically verify OTP & record consent | Base Table | `PK = CASE#<id>`, `SK = PARTY#<phone>` (Condition: OTP matches & `otpExpiry >= now`) | `UpdateCommand` |
| **AP-08** | Update case status & re-index GSI | Base Table | `PK = CASE#<id>`, `SK = METADATA` (`SET status = :s, GSI1SK = STATUS#<newStatus>`) | `UpdateCommand` |
| **AP-09** | Query Mediator Queue by District | `MediatorQueueIndex` | `GSI1PK = JURISDICTION#<district> AND GSI1SK = STATUS#<status>` | `QueryCommand` |
| **AP-10** | Append tamper-evident audit log | Base Table | `PK = CASE#<id>`, `SK = AUDIT#<isoTimestamp>#<action>` | `PutCommand` |
